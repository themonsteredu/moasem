# 모아셈 후속 구현 순서

2026-09-05 기준. 저장소에 구현된 기능과 실제 운영 확인이 끝난 기능을 구분합니다. 기능 하나를 끝내면 확인 방법을 안내하고 다음 단계로 넘어갑니다. 새 화면은 구성 확인을 먼저 받습니다.

| 순서 | 다음 작업 | 사용자가 할 수 있게 되는 일 |
|---|---|---|
| 운영 전 확인 | 대기 중인 로그인·영상 연결·알림톡 배포 검증 | 실제 계정으로 학생을 조회하고 보호자가 리포트를 받는 흐름 확인 |
| 1 | 다국어 보호자 동의와 동의 기록 | 운영자가 넣은 언어별 문구로 보호자 동의 일시·언어 기록 |
| 2 | 보호자 모국어 AI 리포트·수학 용어표 | 강사가 입력한 결과로 한국어·베트남어·중국어 리포트를 해당 언어로 처음부터 작성 |
| 3 | 학생 입장과 과제 사진 제출 | 큰 버튼 세 개의 학생 첫 화면에서 과제 올리기·수업 입장·영상 보기. 채점은 수동 우선 |
| 4 | Zoom SDK 수업 입장·화상 출석 | 이름·회의 정보를 입력하지 않고 입장, 강사는 호스트, 입퇴장 기록과 줌 앱 열기 제공 |
| 5 | 보충영상 시청 기록·자막 | 눌렀는지/끝까지 봤는지를 구분하고 지원하는 영상에서 보호자 언어 자막 제공 |
| 6 | 기관 현황·미제출 주간 알림 | 실제 과제 제출과 출석·오답 자료를 기관 담당자에게 읽기 전용으로 표시 |
| 7 | 사전·사후 진단과 성과보고서 | 학생 변화·출석·제출·시청률을 프로그램별 PDF/DOCX로 출력 |
| 후속 | 사진 자동채점·285개 유형 연결 | 정답지와 오답 유형 자료를 바탕으로 자동 채점하고 강사가 수정 |

다문화 보호자 동의 문구는 운영자가 제공하며 임의로 법률 문구를 확정하지 않습니다. Zoom SDK 연결 값은 Zoom 앱 등록 후 안전한 서버 설정으로 받습니다. 브랜드 색감과 에스코어드림은 유지하며 로고·파비콘 교체는 별도 요청 때 진행합니다.
