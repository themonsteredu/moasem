# 학습 운영 1~4단계

1. 관리자 또는 담당 강사 → 학생 이름 → 과제와 학생 입장: 제목·교재/쪽수·시작/마감일 등록. 오프라인 제출은 상태를 제출/강사 확인으로 변경. 새로고침 후 저장 내용 확인.
2. 학생 링크 새로 만들기: 30일 유효, 이전 링크 즉시 폐기. 학생과 보호자에게만 전달. 학생은 세 버튼으로 수업 입장·사진 올리기·등록된 보충영상을 이용. 사진은 기기에서 축소하고 과제당 5장, 장당 3MB 이하. 비공개 moasem-homework 저장소, 강사에게 5분 사진 링크 제공.
3. 기관 전용 조회 링크: 이번 주 마감 과제 제출 수/전체 수, 이번 주 수업의 오답 상위 3유형. 날짜 기준 한국시간 월~일. 비공개 강사 메모나 과제 사진은 기관 API에서 제외.
4. 진단·성과보고서: 프로그램 선택 → 보고서 생성 → 같은 진단지 HTTPS 링크와 만점 등록 → 사전/사후 점수 입력 → 보고서 재조회. 점수 입력 후 진단지는 잠금. 점수 정정은 같은 학생/진단 재저장.

## 보고서
현재 프로그램에 소속된 학생(중지 포함), 프로그램 날짜 범위와 오늘까지 기록을 사용. 출석은 기록된 회차 기준이며 지각 포함, 인정결석은 분모에 포함. 숙제는 마감된 과제만 집계. 사전/사후는 둘 다 있는 학생끼리 100점 기준 평균. 시작4주/마지막4주 비교가 겹치면 표시, 기록이 없는 구간은 기록 없음. 영상은 추천 영상-학생 조합의 열람/자기 완료확인율이며 실제 끝까지 재생 측정이 아님. 코멘트는 무료 정형 문장.

PDF는 인쇄 창에서 PDF 저장. DOCX는 실제 OOXML 파일로 다운로드. 한글에서 열어 다른 이름으로 저장하면 HWP로 변환 가능(한글 프로그램 필요). 익명화 기본 켜짐: 학생01 형식. 브라우저 인쇄 머리글/바닥글은 필요시 끄기.

## 제한과 검증
자동채점, 유료 AI, 유료 알림톡은 활성화하지 않음. 학생 홈은 인증된 전용 링크 방식(학생 이름/프로그램으로 다른 학생을 검색할 수 없음). 문제지 등록은 파일 공유 링크 방식. 학생 영상 목록은 최근 학습결과 100건에서 최대30개. 과제 화면은 최근100건 표시. 시험자료는 실제 DB 트랜잭션으로 만들고 모두 롤백. 실제 운영 계정 및 휴대폰 사진을 통한 최종 운영 확인은 별도로 필요.
